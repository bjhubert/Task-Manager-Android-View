# Task-Manager
This is a project that let's user enter a list of tasks to complete. Once that's done they can click the checkbox to visually
show that the task has been completed. This project has been re-implemented using Android Views.

Copy the github url.
Go into Android Studio
Select New -> Project from Version Control
Paste the url and add it to an empty folder
Then click clone
Finally, you can run it.

Task re-implemented was Task manager.
